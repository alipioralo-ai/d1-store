# D1 Store

Tienda web de iPhone con preventa del **iPhone 18 Pro Max** e **iPhone Dúo**.

Fotos oficiales de cada modelo, lista de precios en soles y contacto por WhatsApp.

## Contacto

WhatsApp: **+51 997 610 401**

Tienda física: Centro Comercial IMA SUMAQ 265, Calle Maruri, 1er piso — Tienda 135, Cusco

## Cómo correrla

```bash
npm install
npm run dev
```

La app queda en `http://localhost:8080`.

```bash
npm run build
npm run typecheck
```

## Stack

React 19 · TanStack Start · Tailwind CSS v4 · Vite

## Contenido

- Preventa iPhone 18 Pro, 18 Pro Max e iPhone Dúo
- Catálogo iPhone 17 / 16 / 15
- Precios de preventa, contra entrega y por volumen
- Botones de consulta que abren WhatsApp con el modelo elegido
